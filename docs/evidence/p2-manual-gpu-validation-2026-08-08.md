# P2 人工 GPU 验收记录

日期：2026-08-08  
验收人：项目所有者  
阶段：P2——移动参考系与内外部统一  
结论：**通过**

## 验收结论

本轮所有需验证项均被确认可行：

1. 船舱、窗框、船体与外部世界可以共享同一真实透视、遮挡和深度关系；
2. 窗口可以作为真实三维开口观察外部，不需要第二摄影机或 RenderTexture 伪造窗景；
3. 船舶连续转向时，岛屿、港口和固定地标在窗外的视差连续；
4. 船体、船舱结构、家具和船上主体能够保持刚性一致；
5. 世界参考系与船舶参考系之间的对象迁移可行，不产生瞬移、复制或丢失；
6. 客户端表现摇摆可以与权威导航姿态分离；
7. 大坐标下没有观察到影响使用的抖动、空间失真或内外错位；
8. 船舶内部与外部可以作为同一连续三维世界被观察和交互。

## 停止线判断

P2 的核心风险假设已被证实可行：

> 大型载具可以作为具有独立局部坐标系的移动区域存在，同时在客户端视觉上保持统一三维世界、真实窗外视差、内外部连续可见和稳定的大坐标表现。

因此 P2 停止线关闭，允许启动 P3 语义建筑编译器验证。

## 不作为 P2 阻塞项的后续工程

以下事项仍然需要后续实现或独立验证，但不会推翻 P2 结论：

- 正式海洋或空气动力学；
- 船舶刚体碰撞与结构受力；
- 建筑和船舱的正式遮挡淡出、外壳分组与剖视；
- 联网复制、区域权威和跨区域迁移；
- 玩家造船与结构合法性；
- 船战、魔法和 NPC 船员生活；
- 最终材质、光照和美术表现。
