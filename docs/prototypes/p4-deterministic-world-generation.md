# P4：确定性世界生成

## 启动依据

P0～P3 已分别确认基础契约、复杂卷轴摄影机、移动参考系和语义建筑编译路线可行。P4 开始把这些能力放进同一份程序化生成的三维世界中，验证自然地理、交通、聚落、建筑和卷轴路线能否共享同一套世界事实。

## 核心问题

P4 不以“生成看起来随机而丰富的地形”为目标，而是验证下面这条因果链是否成立：

```text
山脊和宏观高程
→ 汇水、河流和海岸
→ 气候与生态
→ 地表通行成本
→ 道路、桥梁和港口
→ 聚落选址与功能
→ 街区、建筑任务书和建筑实例
→ 三维通行网络
→ 卷轴路线与摄影机候选
```

卷轴视角只负责选择如何观察已经成立的世界，不能为了构图移动山脉、河流、建筑和地标。

## 最小世界

第一版固定生成半径为 2 的六边形蜂巢，共 19 个 `AtlasCell`：

- 跨地块山脊；
- 一个完整流域和一条主河流；
- 连续海岸与港湾；
- 一座港镇；
- 陆路主干道和支路；
- 一座固定高塔或山地地标；
- 三条以上跨地块卷轴路线；
- 六栋以上由 P3 建筑蓝图实例化的建筑。

该范围足以验证跨边界连续性、功能因果和多路线观察，不承担无限流式世界的性能压力。

## 第一阶段实现

### `world_generation_core`

引擎无关核心负责：

- 六边形轴坐标、邻接方向和共享边界键；
- `WorldGenerationConfig`、`GeneratorVersion` 和阶段化随机流；
- `WorldManifest` 与 `AtlasCellManifest`；
- 高程、山脊、海陆、气候、生态和地表通行成本；
- 汇水方向、河流和海岸拓扑；
- 道路、港口、聚落和地标；
- 跨地块路线门户和路线图；
- 建筑实例绑定与稳定 ID；
- 语义指纹和结构化验证错误。

### `p4_world_scenario`

提供固定测试配置、生成顺序扰动、反例配置和 P3 建筑蓝图引用。

### `p4_world_trace`

无头报告首先验证：

- 19 格六边形拓扑；
- 相同种子和版本的确定性；
- 打乱地块遍历顺序后结果不变；
- 河流沿非增高方向到达海洋；
- 海岸、道路和路线边界门户成对一致；
- 港镇具备水源、港湾、可建设坡度和交通理由；
- 建筑入口连接道路，建筑实例使用 P3 蓝图；
- 同一固定地标被所有路线引用；
- 结构化失败能够定位到具体约束。

## 第二阶段实现

自动门禁通过后建立 Bevy 世界可视原型：

- 生成连续三维地形、河流、海岸、道路和港镇；
- 从同一语义清单生成建筑近景、外壳和 Massing；
- 使用 P1 卷轴摄影机沿多条跨地块路线观察同一世界；
- 验证远处可见的山脉、港镇和高塔可以真实到达；
- 验证地块边界没有视觉与功能接缝。

## 停止线

P4 只有在以下三类证据全部成立后才通过：

1. 无头确定性与结构约束报告；
2. Bevy 连续世界可视原型；
3. 真实 GPU 人工验收。

P4 通过前不启动 P5 权威服务端、存档与回放。

## 非目标

- 无限世界和正式流式加载；
- 完整板块构造、侵蚀和高精度水动力学；
- 完整程序化城镇和国家；
- 正式植被、天气、材质与最终美术；
- NPC、经济、政治、战争和 Agent；
- 多人同步、区域权威与分布式服务；
- 正式海洋和载具物理。
