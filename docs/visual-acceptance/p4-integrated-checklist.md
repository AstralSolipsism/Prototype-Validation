# P4 综合 Atlas—局部世界—卷轴路线 GPU 验收清单

## 验收目的

本轮只判断完整分层世界技术路线是否成立，不评价最终美术、正式内容规模、性能上限或玩法完成度。

必须验证同一份确定性世界数据能够完成：

```text
Atlas 语义地图
→ 地块地理与历史理解
→ 详细三维世界
→ 真实生成路线
→ 到达同一地标
→ 建筑 LOD
→ 返回 Atlas
```

## 基本操作

- `M`：Atlas / 局部总览切换；
- `Tab`：Atlas 图层切换（高程、地貌、气候、资源、历史）；
- `Q / E`：选择上一个 / 下一个 Atlas 地块；
- `Enter`：进入当前已物化地块；
- `C`：等高线；
- `H`：Atlas 六边形边界；
- `B`：历史与土地利用图层；
- `T`：详细世界路线调试线；
- `1 / 2 / 3`：选择三条路线并开始旅行；
- `Space`：暂停 / 继续；
- `V`：卷轴镜头观察侧；
- `L`：建筑完整结构 / 外壳 / Massing；
- `A / D` 或左右方向键：局部总览环绕；
- 上下方向键：局部总览高度；
- `R`：重置。

## A. Atlas 是独立地图层

- [ ] Atlas 是扁平化语义地图，不是局部三维场景的远距离摄影机；
- [ ] 19 个六边形清晰可选；
- [ ] 高程图层能区分海洋、海岸、低地、高地和山地；
- [ ] 开启等高线后，可以解释哪里高、哪里低以及山脉走向；
- [ ] 山脊、河流、海岸和道路是稳定的跨地块特征；
- [ ] 气候、资源、历史图层切换只改变地图表现，不移动世界对象；
- [ ] 选择地块时，窗口标题显示高程范围、起伏度、可建设比例、人口和主要经济；
- [ ] 某些地块明确包含两种以上主要地貌，而不是一个格子一个颜色标签。

## B. 地块内部详细自然地理

切换到局部总览并绕场景观察：

- [ ] 能明确识别主山脊、山坡、山脚、谷地、河谷、低地、河口、海岸和海洋；
- [ ] 世界不再表现为若干块着色倾斜平面；
- [ ] 河流位于谷地或低地并连续进入河口；
- [ ] 山体、岸线和河流从远处看见后可以走近；
- [ ] 关闭 Atlas 边界后，局部场景中不存在可见六边形接缝；
- [ ] 地形具有连续法线和高程，没有裂缝、重叠或海水爬坡。

## C. 人文历史与当前空间

开启历史图层：

- [ ] 港口位于可用岸线和河口附近；
- [ ] 老城区、新区、农田、桥梁、道路、堡垒/废墟和纪念物在空间上可区分；
- [ ] 聚落不是均匀随机铺设，布局能由水源、港湾、道路和地形解释；
- [ ] 废墟位于历史防御位置，而不是无原因装饰；
- [ ] 新区和新路体现洪灾或冲突后的重建关系；
- [ ] Atlas 历史图层和局部历史对象指向同一聚落与事件体系。

## D. 路线来自详细世界

分别按 `1`、`2`、`3` 完成路线：

- [ ] 路线沿山道、河谷、桥梁、道路、街区或码头生成；
- [ ] 路线节点密度明显高于“地块中心连线”；
- [ ] 不穿越海洋、悬崖、不可通行地形或建筑实体；
- [ ] 跨越至少三个 Atlas 地块且边界连续；
- [ ] 直线、弧线、坡道、路口、纵深和镜头重构仍然可读；
- [ ] 正向旅行稳定；
- [ ] 切换观察侧只改变镜头，不移动道路、建筑、山体或高塔；
- [ ] 三条路线都指向同一个固定高塔。

## E. 地图选择与实际到达对象一致

- [ ] Atlas 中只有一个高塔地标；
- [ ] 局部远景中看到的高塔与 Atlas 标记位置一致；
- [ ] 旅行过程中高塔的方向、遮挡和大小连续变化；
- [ ] 路线终点实际到达该高塔，而不是另一个近似模型；
- [ ] 返回 Atlas 后，地标、聚落和道路位置未改变；
- [ ] 不存在只能作为背景、无法到达的主要山体、港镇或地标。

## F. 建筑跨尺度表现

到达聚落后反复按 `L`：

- [ ] 完整结构、外壳和 Massing 的基座、朝向和总体尺寸一致；
- [ ] LOD 切换不复制、跳位或替换建筑身份；
- [ ] 地图聚落标记、局部建筑群和历史城区属于同一聚落；
- [ ] 建筑不会为了摄影机方向变成单面空壳。

## G. 稳定性

- [ ] 无摄影机穿模；
- [ ] 无明显地形闪烁、深度冲突或接缝；
- [ ] 无对象瞬移、复制或累计偏移；
- [ ] 连续观看和切换模式没有明显晕动；
- [ ] 程序可重复完成 Atlas → 局部 → 路线 → 目标 → Atlas 流程。

## 最终结论

- [ ] 通过；
- [ ] 有条件通过；
- [ ] 失败。

P4 只有在本清单整体通过且自动跨尺度报告全部通过后，才可解除 P5 阻塞。
