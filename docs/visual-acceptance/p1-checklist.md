# P1 GPU 人工验收清单

记录测试机器、GPU、驱动、分辨率、平均帧率、最低帧率，并为每项附截图或录像时间码。

- [ ] 正向自动路线完成，没有摄影机穿模；
- [ ] 反向自动路线完成，没有错误沿用正向切线；
- [ ] 直线路段主体屏幕运动方向稳定；
- [ ] 接近十字路口时所有出口在选择前可辨认；
- [ ] 九十度转向没有让整个世界突然高速旋转；
- [ ] 同一高塔在转向前后位置、尺度和朝向符合真实三维投影；
- [ ] 建筑没有空背面、单面屋顶或错误法线；
- [ ] 主体没有连续超过 0.5 秒被完全遮挡；
- [ ] 路线坡度变化没有导致摄影机翻滚；
- [ ] 1080p 下无明显闪烁或深度冲突；
- [ ] 连续观看 10 分钟后没有明显晕动不适；
- [ ] 失败项记录为可复现问题，没有通过移动地标掩盖。

结论只能选择：`通过`、`有条件通过`、`失败`。
