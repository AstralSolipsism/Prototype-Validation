# P2 GPU 人工验收清单

本轮只验证移动参考系、统一内外空间、真实窗外视差、上下船坐标迁移和大坐标稳定性，不评价正式海洋、美术或物理品质。

## 环境

- [ ] 已记录 commit SHA、工作流运行号、Windows、CPU、GPU、驱动和分辨率；
- [ ] 使用 `mobile_region_visual.exe` 的完整窗口录像；
- [ ] 未启用录屏防抖或运动补帧。

## 同一主视图与真实窗户

- [ ] 船舱、窗框、船体、岛屿、港口和高塔进入同一透视与深度关系；
- [ ] 窗户是实际几何开口，不存在独立画面延迟、分辨率差异或贴图边界；
- [ ] 船转向时，窗外岛屿和高塔的方向、遮挡与视差连续变化；
- [ ] 切换 `C` 的舱内窗口视角和外部剖视视角后，世界对象没有跳到另一套空间。

## 移动参考系

- [ ] 船体持续移动和转向时，船舱、家具和船上主体保持刚性对齐；
- [ ] 表现摇摆开启时，船体和内部内容同步摇摆；
- [ ] 按 `P` 关闭表现摇摆后，权威航迹不发生跳变；
- [ ] 没有因大世界坐标产生窗框、主体、家具或远景抖动。

## 坐标系迁移

- [ ] 按 `B` 离船时，红色主体在世界中的位置保持连续，不发生瞬移；
- [ ] 船继续航行后，已离船主体不再被船体带走；
- [ ] 再按 `B` 登船时，主体世界位置保持连续并重新进入船舶局部参考系；
- [ ] 重复上下船没有产生对象副本、丢失或累计偏移。

## 已知不在本轮范围

- 摄影机—主体遮挡淡出和正式船体剖视由 Issue #6 跟踪；
- 不验证海浪流体、船体动力学、碰撞、联网、玩家造船和完整室内光照；
- 当前盒体与颜色仅用于空间关系验证。

## 结论

只能选择：`通过`、`有条件通过`、`失败`。
