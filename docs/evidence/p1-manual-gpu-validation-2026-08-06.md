# P1 人工 GPU 验收结论

- 日期：2026-08-06
- 验收对象：复杂三维路线卷轴摄影机原型
- 对应分支：`agent/bootstrap-technical-preproduction`
- 结论来源：项目所有者在真实窗口/GPU 环境中的人工观察
- 总体结论：**通过**

## 已确认成立

1. 直线路段稳定；
2. 进入十字路口前，可以看见多个真实三维出口；
3. 九十度转向连续，摄影机运动平滑；
4. 转向完成后能够重新建立横向卷轴画面；
5. 正向和反向路线均成立；
6. 坡道路段画面稳定，没有摄影机翻滚；
7. 固定地标、建筑、道路和主体之间保持统一世界空间关系；
8. 未观察到摄影机穿模、不可接受的遮挡、画面闪烁或晕动不适。

## 已知非阻塞问题

### P1-FOLLOWUP-INPUT

当前左右按键按路线世界方向解释，没有根据当前摄影机的屏幕左右方向重新映射。该问题属于输入语义层，不影响卷轴视图、统一世界坐标或双向路线成立。

跟踪：Issue #5。

### P1-FOLLOWUP-OCCLUSION

建筑位于摄影机与红色主体之间时会遮挡主体，尚未实现透明化、淡出、外壳分组隐藏、剖视和遮挡预算。

该问题只能影响表现可见性，不得改变碰撞、服务端视线、房间边界和建筑结构事实。

跟踪：Issue #6。

## 证据边界

本文件记录验收人的文字结论。当前仓库尚未归档原始录像、固定检查点截图和机器信息；这些材料作为非阻塞证据工程由 Issue #7 跟踪。

## 架构判定

P1 已经证明：

- 世界路线可以在三维空间中发生九十度转向和形成真实路口；
- 摄影机可以通过有限卷轴语法连续重构，而不移动世界对象；
- 同一固定地标可以在正向、反向和转向过程中保持统一世界位置；
- 坡道和复杂路线不必导致摄影机翻滚或晕动；
- P2 可以在该视觉基础上继续验证移动参考系和内外部统一渲染。

**P1 技术停止线：通过。**
