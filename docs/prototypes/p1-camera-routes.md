# P1：复杂路线卷轴摄影机验证

## 风险假设

统一三维世界中的直线、弧线、九十度转弯、十字路口和坡道，可能无法在不移动世界对象、不暴露空背面、不造成镜头剧烈旋转的前提下形成稳定卷轴画面。

## 原型范围

- 手工三维场景，不引入程序化世界生成；
- 直线、九十度转向、弧形斜坡和十字路口支路；
- 多栋完整盒体建筑；
- 转向前后均可见的同一固定地标；
- 九种卷轴语法；
- 航向和构图参数都采用半衰期平滑，禁止语法切换造成镜头跳变；
- 正向与反向无头轨迹报告；
- Bevy 0.19 可视程序。

## 自动证据

- Rust 1.97.1 / Bevy 0.19 工作区编译通过；
- `cargo fmt`、Clippy 和引擎无关测试通过；
- 正向与反向无头摄影机轨迹报告生成成功；
- 架构边界与确定性测试向量通过。

## 人工 GPU 验收

项目所有者确认：

1. 直线路段稳定；
2. 路口进入前可以看见多个真实出口；
3. 九十度转向连续且镜头平滑；
4. 转向后重新建立横向画面；
5. 正向和反向均成立；
6. 坡道画面稳定；
7. 世界空间统一；
8. 未观察到穿模、闪烁或晕动。

详细记录见：`docs/evidence/p1-manual-gpu-validation-2026-08-06.md`。

## 非阻塞后续

- Issue #5：输入按屏幕左右重新映射；
- Issue #6：摄影机—主体之间的遮挡淡出与剖视；
- Issue #7：归档录像、固定截图和截图回归基线。

这些问题属于实现和表现工程，不推翻复杂路线卷轴技术路线，也不阻塞 P2。

## 尚未覆盖

- 正式场景资产的全角度暴露包络；
- 通用摄影机碰撞；
- 正式遮挡预算与建筑剖视；
- 路口选择 UI；
- 观察侧主动切换；
- 大规模场景 GPU 性能。

## 结论

**P1 技术停止线已通过。**

允许启动 P2：移动参考系、船舱内外统一空间、真实窗外视差、上下船坐标系迁移与大坐标稳定性验证。
