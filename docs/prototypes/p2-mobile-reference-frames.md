# P2：移动参考系与内外部统一——下一阶段定义

P2 只有在 P0 编译测试通过、P1 完成第一轮 GPU 检查后启动。

首个样板是一艘 30～60 米船舶，包含甲板、两间船舱、真实窗户、一座岛、一座港口和一个远处地标。验证对象包括：

- `WorldFrame`、`VehicleFrame`、局部姿态和摄影机相对渲染；
- 船舱与外部同一主摄影机、同一透视和同一深度关系；
- 窗口作为可见性门户而不是渲染贴图；
- 上船、下船、靠岸的显式坐标系迁移；
- 船体表现摇摆与稳定内部模拟姿态分离；
- 千公里级全局坐标下内外部无抖动。

P2 仍不引入正式海洋模拟、网络同步、完整物理引擎或玩家建造。
