# P1：复杂路线卷轴摄影机验证

## 风险假设

统一三维世界中的直线、弧线、九十度转弯、十字路口和坡道，可能无法在不移动世界对象、不暴露空背面、不造成镜头剧烈旋转的前提下形成稳定卷轴画面。

## 当前原型范围

- 手工三维场景，不引入程序化世界生成；
- 直线、九十度转向、弧形斜坡和十字路口支路；
- 多栋完整盒体建筑；
- 转向前后均可见的同一固定地标；
- 九种卷轴语法；
- 航向和构图参数都采用半衰期平滑，禁止语法切换造成镜头跳变；
- 正向与反向无头轨迹报告；
- Bevy 0.19 可视程序。

## 尚未验证

真实资产暴露包络、摄影机碰撞、遮挡预算、路口选择 UI、观察侧切换、截图回归、GPU 帧率和晕动舒适度。

## 通过条件

1. 正向与反向无头轨迹均通过速度、角速度、距离和有限值阈值；
2. 正反路线完成 GPU 人工检查；
3. 地标在所有转向中保持唯一世界位置；
4. 摄影机不穿过结构体；
5. 路口先展示出口，再承诺路线，再重构镜头；
6. 建立固定路径截图基线并保存证据。

## 当前结论

代码已准备进入 CI 和 GPU 人工检查，**尚未通过 P1 停止线**。
