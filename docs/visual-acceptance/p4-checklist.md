# P4 GPU 人工验收清单

本轮只验证**确定性世界清单是否能够编译成空间统一、跨地块连续、远景可到达、适配卷轴视角的三维世界**。占位材质、盒体建筑、光照、植被密度和最终美术品质不在本轮评价范围。

## 需要留存的证据

- [ ] 运行 `collect_p4_machine_info.ps1`，保留生成的 `p4-machine-info.txt`；
- [ ] 记录 Windows、CPU、GPU、驱动、分辨率、Workflow run 和 Commit SHA；
- [ ] 录制一段世界总览；
- [ ] 分别录制路线 1、2、3 从起点到港镇的完整过程；
- [ ] 截取港镇、河口、地标、地块边界、建筑三种 LOD 的固定截图；
- [ ] 未启用录屏防抖、运动补帧或后期镜头稳定。

## 操作

- `F`：世界总览 / 卷轴路线跟随视角；
- `1`、`2`、`3`：选择三条生成路线，并回到对应路线起点；
- `Space`：暂停或继续沿路线移动；若已经到达终点，再按会从起点重新运行；
- `V`：切换路线镜头观察侧；
- `L`：建筑完整结构 / 外部壳体 / Massing 体块；
- `H`：显示或隐藏六边形地块边界；
- `P`：显示或隐藏跨地块门户；
- `T`：显示或隐藏三条路线；
- `A / D` 或左右方向键：在世界总览中环绕观察；
- 上下方向键：在世界总览中调整观察高度；
- `R`：恢复初始状态。

窗口标题会显示当前视角、路线、卷轴语法、路线距离、建筑 LOD，以及地块边界和门户开关状态。

## 一、世界总览

先保持默认总览视角，使用 `A / D` 绕世界观察一周，再使用上下方向键改变高度。

- [ ] 能识别 19 个六边形世界地块构成的连续区域；
- [ ] 山地、高地、低地、海岸和海洋具有连续的总体关系；
- [ ] 主河流从内陆高地连续流向海岸和海洋；
- [ ] 河流没有在地块边界突然断开、横跳或反向爬坡；
- [ ] 海岸线在相邻地块之间连续，没有一侧为陆地、另一侧却无对应海面的矛盾；
- [ ] 三条道路都连接真实目的地并汇聚到港镇，不是无目的的孤立线段；
- [ ] 港镇位于河口、海岸和道路汇聚处，视觉直觉上有选址理由；
- [ ] 远处高塔只有一个实例，始终固定在同一座山地或高地上；
- [ ] 没有地块整体漂移、重叠、裂缝或明显高度断层。

按 `H` 显示地块边界后，重点观察边界两侧：

- [ ] 地形表面在共享边界处接合；
- [ ] 河流、道路和路线跨越边界时没有断点；
- [ ] 关闭 `H` 后，正常画面不会依靠边界线掩盖裂缝。

## 二、跨地块门户

按 `P` 显示跨地块门户，同时保留 `H` 和 `T`。

- [ ] 河流跨界位置存在对应门户标记；
- [ ] 道路跨界位置存在对应门户标记；
- [ ] 卷轴路线跨界位置存在对应门户标记；
- [ ] 门户位于两侧地块共享的同一边界位置，而不是两边各有一个错开的入口；
- [ ] 门户只是调试标记，关闭 `P` 后世界本身仍然连续；
- [ ] 没有悬空、落入地面或远离对应河流/道路/路线的门户。

## 三、三条路线的完整通行

对路线 1、2、3 分别执行：

1. 按对应数字键；
2. 按 `F` 进入路线跟随视角；
3. 确保路线正在运行；
4. 不切换路线，让红色主体完整到达港镇；
5. 到达后切回总览核对终点位置；
6. 使用 `V` 切换另一观察侧，重复关键路段。

每条路线均应满足：

- [ ] 起点位于真实世界地形和道路上；
- [ ] 红色主体沿可见的真实道路移动，不是在独立背景前平移；
- [ ] 经过地块边界时主体、道路、地形和摄影机连续；
- [ ] 路线包含直线、轻度纵深、转向、路口或坡道中的相应语法；
- [ ] 九十度或明显转向时镜头连续重构，转向后重新建立横向画面；
- [ ] 路口接近时能够看见真实的其他出口；
- [ ] 坡道中画面稳定，没有翻滚或突然改变世界朝向；
- [ ] 路线最终到达总览中看到的同一座港镇；
- [ ] 不存在路线终点停在港镇外、道路断裂或穿过不可通行山体的情况；
- [ ] 切换观察侧后，世界物体仍在同一位置，没有出现另一套背景。

## 四、远景可达与统一地标

在三条路线的起点和中段分别观察高塔、山地、海岸与港镇。

- [ ] 高塔在不同路线中始终具有同一世界位置、朝向和高度；
- [ ] 高塔的屏幕位置、比例和遮挡随摄影机与主体移动连续变化；
- [ ] 不会在路线切换后复制出第二座塔、瞬移或换成另一套背景塔；
- [ ] 从远处看到的港镇、山地、海岸和高塔能够通过真实路线逐步接近；
- [ ] 接近后看到的近景与远景轮廓能够对应；
- [ ] 世界没有“看得到但永远到不了”的纯背景地标；
- [ ] 摄影机没有为了维持构图而移动高塔、港镇、山体或河流。

## 五、港镇与建筑落位

到达港镇后切换总览和路线跟随视角，从不同方向观察。

- [ ] 六栋建筑落在同一港镇地块内，并围绕道路或广场组织；
- [ ] 建筑没有互相重叠、悬空、深埋或跨越明显不可建设地形；
- [ ] 建筑朝向和入口与道路/广场关系基本合理；
- [ ] 港镇、河口、道路和海岸之间的功能关系容易理解；
- [ ] 从其他地块远看港镇时，建筑总体位置与到达后的近景一致。

反复按 `L` 切换三种表现：

```text
完整结构 → 外部壳体 → Massing → 完整结构
```

- [ ] 三种表现使用同一地形锚点；
- [ ] 建筑基座不移动；
- [ ] 总宽度、总高度、朝向和主体轮廓不发生明显跳变；
- [ ] 切换不产生重复建筑、残留构件或闪烁；
- [ ] Massing 可以省略门窗细节，但不能变成位置和尺寸不同的另一栋建筑。

## 六、空间统一与穿帮检查

- [ ] 总览和三条路线观察的是同一份世界几何；
- [ ] 河流、道路、港镇、高塔和建筑没有因路线不同而出现不同版本；
- [ ] 不存在单面建筑、空背面或只面向某条路线的假立面；
- [ ] 摄影机没有穿入地形、建筑或高塔；
- [ ] 没有明显深度闪烁、表面重叠抖动或地块缝隙；
- [ ] 红色主体可能被占位建筑短暂遮挡，但不能因此判定世界空间不统一；正式遮挡淡出仍由 Issue #6 跟踪；
- [ ] 连续观看三条路线没有明显晕动或方向丢失。

## 七、明确不在本轮范围

以下内容不得作为 P4 失败理由，除非它直接掩盖空间或功能错误：

- 占位颜色和盒体建筑不够美观；
- 缺少正式植被、岩石、海浪、天气、材质和环境音；
- 河流和海岸不是高精度流体或侵蚀结果；
- 港镇规模小、建筑种类少；
- 没有 NPC、经济、战斗、载具或联网；
- Debug/技术验证构建的帧率不能代表最终性能；
- 摄影机遮挡淡出尚未实现。

## 结论标准

### 通过

只有在以下核心假设全部成立时选择：

- 世界清单能够形成连续三维世界；
- 河流、海岸、道路和路线跨地块连续；
- 港镇选址和建筑落位具备基本功能合理性；
- 三条路线能够到达同一个港镇；
- 同一山脉、港镇、高塔和建筑在不同路线中空间统一；
- 远处可见内容真实可达；
- 建筑 LOD 共用同一锚点和轮廓；
- 不需要移动、复制或替换世界对象来适配卷轴构图。

### 有条件通过

总体路线成立，但仍存在可以定位的局部地形平滑、道路形态、镜头参数、建筑朝向或遮挡问题。必须记录问题位置、路线编号、录像时间码和是否阻塞 P5。

### 失败

出现任一基础性问题：

- 地块无法形成连续世界；
- 河流、海岸、道路或路线在边界断裂；
- 三条路线看到的是不同版本的世界；
- 远景地标不可到达或必须伪造；
- 卷轴镜头必须移动真实世界对象才能成立；
- 港镇和建筑无法落在合理可通行空间；
- 建筑 LOD 无法保持同一锚点与尺度。
