# P4 地区级物化、建筑贴地与路线贴地综合人工验收

## 验收目的

本轮重新验证此前失败的三项基础假设：

1. AtlasCell 是约 4 km 尺度的地区级语义容器，不是一个小型 TerrainTile；
2. 进入局部世界后，只激活所选地区的高精度实景，相邻地区仅以边缘带或低分辨率代理保持连续；
3. 建筑和路线必须具有明确的地表、基础或桥梁语义，不得漂浮、埋地或以修改 Y 值掩盖穿模。

本轮仍是技术原型，不评价最终美术、正式内容密度或最终性能。

## 基本操作

- `M`：Atlas / 当前地区局部总览切换；
- `Tab`：切换 Atlas 图层（高程、地貌、承载力）；
- `Q / E`：选择上一个 / 下一个 Atlas 地区；
- `Enter`：激活当前所选地区；
- `1 / 2 / 3`：选择三条跨地区路线并开始旅行；
- `Space`：暂停 / 继续路线；
- `V`：切换卷轴镜头观察侧；
- `L`：建筑 Full / Shell / Massing；
- `N`：显示 / 隐藏六个相邻地区的低分辨率代理；
- `G`：显示 / 隐藏建筑基础；
- `H`：显示 / 隐藏当前地区六边形边界；
- `T`：显示 / 隐藏路线；
- `A / D` 或左右键：局部总览环绕；
- 上下键：调整局部总览高度；
- `R`：重置。

## A. 地图与地区尺度

- [ ] Atlas 中仍有 19 个六边形地区；
- [ ] 窗口标题显示单格约 4.0 km 对边距离；
- [ ] AtlasCell 的地图表现和局部三维表现明显是两套尺度层；
- [ ] 选择不同地区后按 `Enter`，局部内容、地貌中心和激活集合会真实切换；
- [ ] 局部总览不再显示整个 19 格 Atlas 的完整高精度实景；
- [ ] 一个地区内部能够看到山坡、谷地、河流或低地、建设区等多种内容，而不是一个小型平面；
- [ ] 当前地区的空间足以容纳聚落、外围地形和多条路线分支。

## B. 独立物化与邻区连续

在局部总览中反复按 `N`：

- [ ] 当前地区始终保持高分辨率；
- [ ] 相邻地区只以明显更低分辨率的代理出现；
- [ ] 关闭邻区代理后，可以清楚确认高精度主体只有一个地区；
- [ ] 打开邻区代理后，边界高程连续，不出现裂缝或台阶；
- [ ] 相邻代理不会突然覆盖当前地区或产生大面积重叠闪烁；
- [ ] 从路线跨入相邻地区时，高精度激活地区发生切换，但主体、路线和地标不瞬移。

## C. 建筑落位和基础

在港镇地区查看建筑并反复按 `G`、`L`：

- [ ] 所有建筑主体都坐落在明确基础之上；
- [ ] 建筑底部不悬空；
- [ ] 未声明地下空间的建筑不埋入地形；
- [ ] 小坡地建筑以台基或分层基础连接地面；
- [ ] 基础关闭时，仅隐藏调试表现，不改变建筑位置；
- [ ] Full、Shell、Massing 共用完全相同的基座位置、朝向和总体尺寸；
- [ ] 切换 LOD 时建筑不会上下跳动；
- [ ] 高塔和普通建筑都具有一致的地形落位关系。

## D. 路线贴地与工程结构

分别完成路线 1、2、3：

- [ ] 普通路段始终贴着地形表面，保持稳定的小幅离地显示偏移；
- [ ] 普通路段不进入山体或地底；
- [ ] 普通路段不会为了降低坡度而在空中悬浮；
- [ ] 路线 1 的河流跨越处使用可见桥面，而不是普通路线直接穿水或穿地；
- [ ] 桥面高于河谷或水面，两端与地面路线连续；
- [ ] 三条路线各跨越至少三个 AtlasCell；
- [ ] 跨格时路线几何连续；
- [ ] 路线旅行过程中高精度地区自动跟随主体切换；
- [ ] 卷轴摄影机只改变观察方式，不移动地形、建筑、桥梁或高塔。

## E. 远景和身份

- [ ] Atlas 中只有一个目标高塔；
- [ ] 三条路线均抵达同一个高塔；
- [ ] 高塔在邻区代理、当前地区实景和路线终点之间位置连续；
- [ ] 进入不同地区后，高塔不会复制或换成另一实例；
- [ ] 返回 Atlas 后，地区、路线和目标位置未改变。

## F. 稳定性

- [ ] 无摄影机穿模；
- [ ] 无地形接缝、深度闪烁或大面积重叠；
- [ ] 无建筑漂浮或穿地；
- [ ] 无普通路线穿入地底；
- [ ] 无对象瞬移、复制或累计偏移；
- [ ] 可以重复完成 Atlas → 选择地区 → 局部实景 → 跨地区路线 → 目标 → Atlas。
