# P3 GPU 人工验收清单

本轮只验证语义建筑蓝图的多种派生表现是否同源、完整、可剖视、可局部更新，并能同时绑定静态世界和移动参考系。不评价最终建筑美术、正式建造界面或结构力学。

## 环境

- [ ] 已记录 commit SHA、工作流运行号、Windows、CPU、GPU、驱动和分辨率；
- [ ] 使用 `building_visual.exe` 完整窗口录像；
- [ ] 未启用录屏防抖、运动补帧或后期缩放；
- [ ] 在 1080p 或更高分辨率下完成检查。

## 操作

- `M`：切换完整结构 / 外部壳体 / Massing 体块；
- `X`：依次切换北、东、南、西、屋顶剖视和无剖视；
- `W`：新增或移除北侧展示窗；
- `O`：暂停或继续右侧移动平台；
- `A` / `D` 或左右方向键：环绕观察；
- 上下方向键：调整摄影机高度；
- `R`：恢复初始状态。

## 完整三维结构

- [ ] 使用 `A/D` 绕建筑一周，正面、背面、左右侧面和屋顶均真实存在；
- [ ] 门窗是墙体真实开口，不是贴在完整墙面上的图案；
- [ ] 从门窗和剖视方向观察时，室内墙、楼板和楼梯存在；
- [ ] 没有单面墙、空背面、错误法线或明显悬空结构；
- [ ] 两层之间的楼梯在空间上连续，未出现连接到不存在楼层的情况。

## 同源表现

- [ ] 按 `M` 在完整结构、外部壳体和 Massing 间切换时，建筑锚点不移动；
- [ ] 三种表现的基座、总高度、宽度、深度和主体轮廓一致；
- [ ] 外部壳体隐藏室内构件，但门窗与屋顶位置仍和完整结构一致；
- [ ] Massing 只删除细节，不产生明显缩放、旋转或整体跳位；
- [ ] 左侧固定建筑和右侧移动建筑始终具有完全相同的局部结构。

## 剖视

- [ ] 在完整结构模式下，按 `X` 能分别隐藏北、东、南、西外壳和屋顶；
- [ ] 剖视只改变对应表现构件的可见性，不移动剩余结构；
- [ ] 切换方向时没有大面积闪烁、残留构件或错误隐藏室内分隔墙；
- [ ] 屋顶剖视后能够清楚观察二层室内；
- [ ] 取消剖视后所有外壳完整恢复。

## 局部增量修改

- [ ] 按 `W` 后只在指定北侧墙段新增展示窗；
- [ ] 新增窗户后，其他墙、楼层、屋顶和 Massing 不移动或重建成不同形状；
- [ ] 窗户开口、窗框、外部壳体和剖视分组同步更新；
- [ ] 再按 `W` 移除窗户后，墙体完整恢复；
- [ ] 左右两个建筑实例同时得到相同局部修改；
- [ ] 多次往返切换没有重复窗框、残留洞口或累计误差。

## 移动参考系复用

- [ ] 右侧建筑随平台移动和轻微转向时，墙、楼板、屋顶、楼梯和开口保持刚性对齐；
- [ ] 左右两栋建筑的局部比例和构件关系一致；
- [ ] 暂停或恢复平台运动不会改变建筑蓝图和表现模式；
- [ ] 剖视、Massing 和增量窗户修改在移动实例上与静态实例一致。

## 已知不在本轮范围

- 当前模型由程序生成的盒体和简化屋顶组成，不代表最终美术；
- 不验证承重、结构破坏、复杂屋顶、任意曲线墙、体素编辑或施工过程；
- 不验证正式 NPC 室内寻路和交互；
- 不验证联网建造、权限、资源消耗和冲突解决；
- 正式摄影机遮挡淡出仍由 Issue #6 跟踪。

## 结论

只能选择：`通过`、`有条件通过`、`失败`。

若出现以下任一情况，应判定失败：

- 三种表现之间建筑整体位置、尺度或主体轮廓不一致；
- 建筑只有面向某一镜头的表面；
- 剖视必须删除或移动真实结构才能成立；
- 新增一个窗户导致整栋建筑发生不可解释的变化；
- 同一蓝图在静态和移动参考系中产生不同局部结构。
